## 5. Best Entry Order

Use this exact order:

1. Enter bottled drinks and cans in `Finished Products`.
2. Enter spirit bottles/shots/doubles/glasses in `Finished Products`.
3. Enter the Bar raw/store items in `Raw Materials`.
4. Receive opening Bar stock in `Store Stocks`.
5. Add recipe rows for:
   - bottle sales
   - shots
   - doubles
   - glasses
6. Add only the 3 simple cocktails after that.

## 6. Best First Dry Run

First test with:

- bottled drinks
- one spirit shot
- one double
- one simple cocktail

Suggested first test items:

- Tusker Bottle
- Vodka Bottle
- Vodka Shot
- Vodka Double
- Gin Tonic

That gives you:
- direct resale flow
- full-bottle spirit deduction
- measured spirit deduction
- simple cocktail deduction
